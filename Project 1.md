# Event Registration Portal

## Project Overview

The Event Registration Portal is a web-based application developed to simplify the process of event registration and management. Users can view event details and register online easily. The system helps administrators manage participant information efficiently using MySQL database connectivity.

---

# Technologies Used

| Category   | Technology |
|------------|------------|
| Frontend   | HTML, CSS |
| Backend    | Java |
| Database   | MySQL |

---

# Features

| Feature | Description |
|---------|-------------|
| User Registration | Users can register for events online |
| Event Management | Admin can manage event details |
| Login System | Secure login for admin and users |
| Database Storage | Stores participant details in MySQL |
| User-Friendly Interface | Simple and easy-to-use design |

---

# Project Modules

| Module Name | Description |
|-------------|-------------|
| Home Module | Displays homepage and event details |
| Registration Module | Allows users to register for events |
| Login Module | Provides authentication for users and admin |
| Database Module | Stores registration and event data |
| Admin Module | Helps admin manage participants |
